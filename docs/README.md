# docs/

Human- and AI-readable documentation output — as opposed to `tests/` (executable) and
`reports/` (generated evidence).

- [qa-digest/](qa-digest/) — output of the QA Digest skill (`skills/qa-digest.md` /
  `qa-digest-lite.md`): living knowledge base of the app under test.
- [rca/](rca/) — root cause analysis for significant/recurring defects.
- [test-plans/](test-plans/) — per-release or per-feature test plans.
- [issue-tracker/](issue-tracker/) — issue log (Excel-compatible CSV), severity/priority matrix,
  traceability matrix.
- [release-notes/](release-notes/) — QA sign-off notes per release.
